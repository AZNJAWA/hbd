# 🎂 HBD Website

Website sederhana untuk memberikan ucapan ulang tahun secara interaktif.

## ✨ Tentang Project

Project ini dibuat sebagai hadiah berupa website ulang tahun.

Di dalamnya terdapat beberapa bagian seperti:

* 🎉 Ucapan selamat ulang tahun
* 🎁 Interaksi tombol
* 🎵 Musik
* 💫 Animasi CSS
* 🖱️ Interaksi menggunakan JavaScript
* 📱 Tampilan yang dibuat agar dapat digunakan di browser

## 🛠️ Teknologi

Project ini dibuat menggunakan:

* **HTML** untuk struktur halaman
* **CSS** untuk tampilan dan animasi
* **JavaScript** untuk interaksi
* **GitHub Pages** untuk hosting

## 🎨 Fitur

Website memiliki beberapa tahap yang dapat dilanjutkan menggunakan tombol.

JavaScript digunakan untuk mengatur perpindahan antar bagian halaman, interaksi tombol, serta menjalankan animasi pada saat musik dimainkan.

## 📚 Pembelajaran

Project ini juga dibuat sebagai latihan untuk memahami:

* Struktur HTML
* CSS Flexbox
* CSS Animation dengan `@keyframes`
* JavaScript DOM
* `addEventListener`
* Manipulasi element dengan JavaScript
* HTML Audio
* Deployment menggunakan GitHub Pages
